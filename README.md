# Crowdfunding and Fundraising Platform

## Project Overview

The Crowdfunding and Fundraising Platform is a full-stack web application developed using Python and Flask. It enables individuals, non-profit organizations, and communities to create fundraising campaigns and receive donations from supporters through a simple and user-friendly interface.

The platform provides secure user registration and login, campaign creation and management, campaign browsing, and donation tracking. It is designed to make fundraising transparent, accessible, and easy to manage.

This project is being developed as a Capstone Project to demonstrate full-stack web development skills, including frontend design, backend development, database integration, and version control using Git and GitHub.

## Objectives

- Build a secure crowdfunding platform using Python Flask.
- Allow users to register and log in securely.
- Enable users to create and manage fundraising campaigns.
- Display active campaigns for public viewing.
- Store campaign and user information using SQLite.
- Provide a clean, responsive, and user-friendly interface.

## Tech Stack

- **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite
- **Version Control:** Git & GitHub
- **Development Environment:** Visual Studio Code

## Key Features

- User Registration and Login
- Create, Edit, and Delete Campaigns
- Browse Active Campaigns
- Campaign Details Page
- Donation Tracking
- User Dashboard
- Responsive User Interface
- Admin Management (Future Enhancement)
