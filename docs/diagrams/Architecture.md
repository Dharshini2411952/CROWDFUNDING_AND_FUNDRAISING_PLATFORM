# Crowdfunding and Fundraising Platform Architecture

## Overview

The Crowdfunding and Fundraising Platform is a web application that allows users to create fundraising campaigns and donors to contribute securely.

## Components

### Frontend
- React.js
- Tailwind CSS

### Backend
- FastAPI
- JWT Authentication

### Database
- MySQL

### External Services
- Payment Gateway
- Email Service

## Flow

User
↓

React Frontend
↓

FastAPI Backend
↓

MySQL Database

Backend also connects to:
- Payment Gateway
- Email Service
